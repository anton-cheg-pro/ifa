# Tone checklist (UA public copy)

**Purpose:** FIN-COPY-07 — editorial pass before deploy (Story 001 US1, `docs/tasks.md`).

**Approve:** product owner (Anton). Financial claims: `finance-analyst` per AGENTS.md.

## Narrative voice

- Professional, calm, educational — not hype or sales pressure.
- Sentence-case headings in UI where the design system expects it.

## Avoid in narrative (not inside client quotes)

| Avoid | Prefer |
|-------|--------|
| Starting a sentence with **бо** (causal) | «тому що», «адже», «через те, що», or restructure |
| **тобто** as filler | Cut or use «тобто» only when defining a term |
| **шалені**, **проапгрейдити**, heavy slang | Neutral UA |
| **найкращий** / **#1** / guaranteed returns | Verifiable facts only; disclaimers |
| Promised **%** returns | Illustrative examples + «минула дохідність…» |

## Allowed

- **бо** inside direct quotes or client testimonials.
- Industry terms (ETF, AUM) with brief gloss on first use if needed.
